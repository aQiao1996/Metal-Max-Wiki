# 0.99 已核验数据

本目录只接收 `verification_status` 为 `verified_0_99` 的记录。网络来源中的“0.9 汉化”、日版和其他相近版本资料只能保存在 `data/raw/mm2r/0.99/candidates/`。

可接受的 0.99 核验证据包括：

- 本机 0.99 游戏界面中的可辨识字段；
- 用户提供并确认来自 0.99 的截图；
- 可重复的存档观察结果；
- 可重复的本地数据提取结果。

核验时必须保留候选数据的来源引用，不得仅凭记忆或相近版本攻略升级状态。

`equipment-names.json` 只核对 `names.zh_099` 字段，范围为 `equipment_names_only`。当前 457 条均有分类内唯一、双向唯一的对应：291 条同名，140 条由至少三个完整基础参数及必要价格对应，26 条依据独立条件逐项核对。最后一批保留完整参数字节、原资料原值和来源哈希；以职业投影、特性、配方、掉落物品 ID 或同族参数区分重合项。两条人类 LOVE 机器分别对应 1223 与 1232 配方，使用不同物品 ID，不按同名合并。人工核对输入在 `data/raw/mm2r/0.99/rom/identity-reviews.json`，重读检查来源、字节及独立条件唯一性。每条记录保留本机 ROM 指纹、物品编号、记录与字符串位置、匹配名称及关联参数，不包含 ROM 原文件或存档。

名称核对不提升整条装备的状态，数值、星级、获取方式与机制继续使用原候选资料。登记版本来自用户指定的 0.99 文件，内部游戏代码不能独立证明汉化补丁版本。重新提取会核对登记 SHA-256，拒绝同名的其他文件。

`equipment-parameters.json` 范围为 `equipment_base_parameters_only`，保存 457 条装备的 1543 个未加星未改造基础字段。1531 个同条件字段相同，4 个有差异，8 个条件不足；保留原始编码、单位、位置、来源对照与依赖哈希。补充基础值直接来自已定位的原始总表，不从一星或三星详情反算。没有同条件数据时保留空参考，不推算星级；差异暂不覆盖网站值。

核验状态只用于数据维护，不在阅读页面展示；正常出处、游戏使用条件与来源差异仍保留。
